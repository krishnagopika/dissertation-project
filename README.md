# Emotion and Sentiment Analysis from Speech and Text Models

## Overview (placeholder)

This dissertation project focuses on capturing emotion and sentiment from multimodal inputs using advanced speech and text models. The project investigates methods to extract emotional cues and sentiment information from:

- **Speech audio**: Using state-of-the-art speech recognition and acoustic feature analysis
- **Text transcriptions**: Leveraging NLP models for semantic and emotional understanding
- **Multimodal fusion**: Combining both modalities for comprehensive sentiment analysis
